# 资讯视频生成

在本仓库运行，使用 Node.js 22+，不依赖个人目录或其他技能。适用于 Codex 及具备文件/命令/浏览能力的 Agent。输入用户的主题、RSS 清单和制作范围；不自动安装到其他 Agent。

- 选题、稿件、事实核验：读 [编辑工作流](../../docs/workflow.md)，从用户指定 RSS 做一次采集，不引入强制聚合平台或定时双轮流程
- 输入与缓存：读 [数据格式](../../docs/data.md)，复用稳定 ID 和未改变的有效素材，保留原始证据与新增细节
- 采集、截图、配音、组装、预览和交付：读 [制作命令](../../docs/production.md) 和仓库 README 的命令示例

精选表示减少新闻数量；入选产品/模型应讲清实际用途、变化、实例及开放条件，口播自然连接，不念固定提纲。正文按企业连续编排。夸张表达须有事实基础，新闻状态与限定不可改变。语速统一 1.1，按语义留句间停顿。

先验证已有依赖与当前 runs/ 状态，缺失凭据时报告，不打印密钥。只有明确制作并配置了声音才调用收费 TTS，dry run 不收费。不要复制用户形象、声音样本、订阅凭据或历史稿件到版本控制。默认通用模板没有个人角色。

截图成功不等于核验完成，实际看图后记录收据。审核时看每句、切换和首尾关键帧；完整试听只在实际做过时声称。用户要求仅预览则不导出；导出后只做本地交付，不附带上传、发布或定时任务。
